# poemDev
Develop an R implementation of the POEM analysis

*** MATLAB ***

In the matlab console, switch the working directory to this repo and run:

[Results, T, Dx] = poemAnalysis_v3_1;


*** R ***

out <- poemAnalysis_v3_1("POEM_v3.1_April 11, 2024_12.18.csv")

returns a named list with out$Results, out$T, and out$Dx
